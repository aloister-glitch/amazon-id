Amazon ID GrabberPolítica de Privacidade

✓ Não coleta dados dos usuários

Esta Política de Privacidade descreve como a extensão Amazon ID Grabber lida com as informações dos usuários.

O que a extensão faz

A extensão Amazon ID Grabber lê o conteúdo da página da Amazon atualmente aberta no navegador do usuário para localizar e exibir o Amazon Customer ID associado à conta logada. O ID é exibido na tela e copiado para a área de transferência do próprio dispositivo do usuário.

Coleta de dados

A extensão não coleta, armazena, transmite nem compartilha nenhum dado do usuário. Nenhuma informação é enviada a servidores externos. Todo o processamento acontece localmente no dispositivo do usuário.

Permissões utilizadas

activeTab: necessária para ler o conteúdo da aba ativa da Amazon onde o usuário está logado.

scripting: necessária para executar o script de extração do Customer ID no conteúdo da página.

clipboardWrite: necessária para copiar automaticamente o Customer ID para a área de transferência do usuário.

Host permissions (amazon.com.br, amazon.com): a extensão funciona exclusivamente em páginas da Amazon.

Compartilhamento de dados

Nenhum dado é vendido, transferido ou compartilhado com terceiros, sob nenhuma circunstância.

Código remoto

A extensão não utiliza código remoto. Todo o código está empacotado localmente no arquivo da extensão.
